# Cat Delivery: A Little Letter

A short illustrated browser adventure designed for landscape phones. No npm, build step, backend or third-party assets needed.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html` and the entire `assets` folder to the repository root.
3. Open **Settings → Pages → Deploy from a branch → main → / (root)**, then save.
4. Open the generated HTTPS link in Safari or Chrome and rotate the phone to landscape.

## Controls
Touch: left/right buttons, jump, paw to interact. Desktop: arrows or A/D, space/up to jump, E/Enter to interact.

## Gameplay
Find the letter in the garden, help the rabbit in the forest, help the bird in the village, and deliver the letter at sunset. Walk right to transition between chapters. At the end, tap to reveal the final screen. Music icon toggles synthesized interaction sounds.

## Notes
The game uses adapted crops from an AI-generated visual concept, with an animated Canvas cat and interactive overlays. It is a small playable gift, not a fully animated commercial game. The original collage contains baked-in scene elements; the extracted scenery has been cropped to reduce visible mock UI. Playtest on the recipient's phone before sharing.
