# Cat Delivery — A Little Letter ♡

Готовая статическая браузерная мини-игра для GitHub Pages. 4 главы: сад, лес, деревня, последний домик.

## Установка

1. Распакуйте ZIP.
2. Загрузите **index.html, game.js и папку assets** в корень репозитория GitHub.
3. Settings → Pages → Deploy from a branch → main → /(root).
4. Откройте опубликованную ссылку в Safari или Chrome и поверните телефон горизонтально.

## Управление

- На телефоне: ← →, ↑ прыжок, ♡ взаимодействие.
- На компьютере: стрелки или A/D, пробел, E/Enter.
- Для перехода к следующей главе нужно выполнить задание и пройти вправо до края.
- Котика можно гладить, нажав на него.
- Звук включается только после взаимодействия с игрой (ограничение браузеров).

## Исправления

- Оригинальные чистые SVG-локации без встроенных кнопок, текстов или персонажей.
- Отдельный SVG-спрайт кота, исключены дубли персонажей.
- Адаптивная игровая ширина под любой горизонтальный экран, включая iPhone.
- Реальные предметы и последовательные задания; полное сохранение прогресса глав.
- Отдельная финальная сцена и письмо с «Я тебя люблю. ❤️».
- Нет сторонних библиотек, сборщиков или сетевых зависимостей.

## Ограничения

Это самостоятельная стилизованная SVG-игра, а не покадровая hand-painted анимация из рекламного концепта. Полное тестирование на конкретной модели iPhone необходимо провести после публикации.
